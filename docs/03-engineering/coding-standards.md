# CODING STANDARDS — Abqoor

## Purpose
Defines coding conventions for all backend and frontend systems.

---

## Codex Instructions

### 1. Simplicity First
- Prefer simple solutions over complex abstractions
- Avoid premature optimization

---

### 2. Modular Design
- Separate concerns clearly:
  - auth
  - questions
  - sessions
  - progress

---

### 3. Naming Conventions
- Use clear descriptive names
- Avoid abbreviations unless standard

---

### 4. Database Rules
- No schema changes without documentation update
- All models must reflect /docs/database.md

---

### 5. API Rules
- All endpoints must be versioned
- No undocumented endpoints
