# User Journey

## Purpose

Document the expected learner journey through Abqoor.

## Overview

The learner journey is designed to keep students focused on consistent improvement while minimizing unnecessary complexity.

---

## 1. Registration

The student:

- Creates an account.
- Signs in.
- Accesses the dashboard.

---

## 2. Start Study Session

The student:

- Starts a new study session.
- Receives a personalized set of questions.

---

## 3. Answer Questions

For each question:

- A question image is displayed.
- The student selects an answer.
- The answer is recorded.

---

## 4. Session Completion

After all questions are completed:

- The session ends.
- Results are calculated.
- Performance is stored.

---

## 5. Progress Review

The student can view:

- Overall progress
- Topic strengths
- Topic weaknesses
- Historical improvement

---

## Continuous Learning Loop

1. Start session.
2. Answer questions.
3. Receive results.
4. Update mastery.
5. Generate a better future session.
6. Repeat.
